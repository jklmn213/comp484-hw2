On this page you’ll find a quick reference to common HTML terms and a table of frequently used named character entities.

HTML Terms

Attribute
An HTML element property that provides additional information or functionality for an element. Attributes appear as a name/value pair with the value contained in quotation marks.
Block-Level Element
HTML tags that create blocks of content within the document, such as headings and paragraphs. Block-level elements typically stack one on top of each other based on the order they appear in the code.
Child Element
Any HTML element that is contained inside another HTML element. Child element tags must close before their parent element tags.
Closing Tag
Appears after an element’s content and indicates the end of an element. It is identical to an element’s opening tag with the addition of a forward slash.
Comment
Reference information added to the code. It may include an overview of complex code, a reminder for future authors, or communication within a team.
CMS
CMS is short for Content Management System. It refers to a system designed to allow users to create and maintain content.
CSS
Cascading Style Sheets, or CSS, is a presentation language used to control the presentation and layout of web pages.
Doctype
Short for Document Type Declaration. It appears at the top of HTML documents to trigger standards mode.
DOM
The DOM, or Document Object Model, is a representation of documents like HTML. Tags are represented by “nodes.”
Elements
HTML elements consist of an HTML tag, used to identify the content, and the content itself. This term is often used interchangeably with “tags,” although technically tags refer only to the tag itself.
FTP
FTP stands for File Transfer Protocol. It is used for transferring files from one server to another.
HTTP
HTTP, or Hypertext Transfer Protocol, controls the formatting and transmission of HTML pages across web servers.
Inline-Level Elements
Elements that appear within the normal flow of text. Unlike block-level elements, inline-level elements do not start new lines.
JavaScript
A scripting language used to control functionality and behavior on the web.
Metadata
Additional information about the document or document content, typically stored in meta tags.
MIME Type
Short for Multipurpose Internet Mail Extensions. MIME types tell user agents what type of file or program is being used.
Parent Element
An HTML element that contains another element. An element can be a child of one element and the parent of another.
Replaced Element
An HTML element whose contents are replaced by something else. Examples include images and videos.
Tag
Markup characters that indicate what type of content appears on the page. Most tags consist of both an opening and closing tag.
URL
URL stands for Uniform Resource Locator. It serves as the address of a document or resource on the web.
W3C
The W3C, or World Wide Web Consortium, is the standards body responsible for authoring the HTML specification.
